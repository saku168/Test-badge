# Test-badge

A small sandbox repository for learning Git and GitHub workflows.

## Practice workflow

1. Create a branch for one focused change.
2. Make and commit the change.
3. Open a pull request and explain what changed.
4. Review the diff and run any relevant checks.
5. Merge the pull request when it is ready.

## Notes

GitHub profile achievements are awarded automatically by GitHub when their criteria are met. This repository is for practicing real contributions, not generating artificial activity.
